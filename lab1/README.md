# Лабораторная №1: Wine Quality

**[lab01.ipynb](lab01.ipynb)** — основной файл для демонстрации. В нём 10 разделов:
данные → разбиение → baseline → регрессии → лес → бустинг → сравнение → важности → ошибки → итоги.
Код обучения находится в ячейках, графики Matplotlib и результаты уже сохранены.
Шпаргалка с соответствием заданию и темами устного ответа — **[DEFENSE.md](DEFENSE.md)**.

## Запуск

После [установки зависимостей](../README.md#выполненные-лабораторные-работы) выполните из корня репозитория:

```bash
cd lab1
.venv/bin/python -m jupyterlab lab01.ipynb
```

Выбери ядро **Python (ML lab)**. Для пошагового запуска используй **Shift+Enter** сверху вниз.
Для полного — **Kernel → Restart Kernel and Run All Cells**, затем **Cmd+S**.
Для просмотра готовых графиков запуск не требуется; слева доступно оглавление.

## Что находится в папках

```text
lab1/
├── lab01.ipynb          # основной ход работы для защиты
├── DEFENSE.md           # что показать и рассказать по каждому требованию
├── src/
│   ├── data.py          # проверки, группы повторов, диагностика ошибок
│   ├── plots.py         # графики Matplotlib
│   └── results.py       # сохранение таблиц и настроек
├── scripts/
│   └── verify_notebook.py  # полный запуск и технические проверки
├── wine+quality/        # исходные CSV, .names и объединённая таблица
│   └── splits/          # фиксированные train.csv и test.csv
├── results/             # результаты, история опытов, контрольные значения
└── requirements.txt
```

Вспомогательные модули отдельно запускать не нужно. Служебные импорты свёрнуты.
Последняя кодовая ячейка сохраняет CSV и настройки в `results/` и тоже свёрнута.
Код обучения и прогнозирования всех моделей остаётся открытым.
`experiments.csv` — история прежних опытов, `reference.json` — контрольные метрики
и хеши до переноса в notebook. Эти два файла нужны и не пересоздаются.
Исходные данные и сохранённые выборки не перезаписываются.

## Проверка

Из каталога `lab1/`:

```bash
.venv/bin/python -B scripts/verify_notebook.py
```

Проверка заново выполняет весь notebook, сохраняет выводы и сравнивает их с прежними:
20 кодовых ячеек, 8 рисунков, отсутствие ошибок, сохранность шести файлов данных,
нулевое пересечение групп train/test, совпадение метрик и прогнозов.
Технические проверки вынесены из notebook, чтобы не мешать демонстрации.

## На другом компьютере

Из каталога `lab1/`. Проверено на Python 3.12.9:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m ipykernel install --prefix .venv --name ml-lab --display-name 'Python (ML lab)'
.venv/bin/python -m jupyterlab lab01.ipynb
```

Для передачи нужны файлы проекта и данные;
папку `.venv` передавать не нужно. Обучение не требует интернета.

Лучший локальный результат: **Random Forest — RMSE 0,678809, MAE 0,519447**.
В задании порог 0,70 относится к скрытой выборке; её результат пока неизвестен.
