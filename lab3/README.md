## Эксперимент

Использована задача Titanic из ЛР2 и одна прежняя модель — `GradientBoostingClassifier`. Исходная конфигурация: `n_estimators=200`, `learning_rate=0.1`, `max_depth=3`. Метрика — F1 класса `Survived=1`. Сохранены те же признаки и стратифицированное разбиение 80/20 (`random_state=42`); предобработка обучается внутри `Pipeline` на каждом fold. Пять стратифицированных folds используются только внутри train. Test не участвовал в поиске и оценён после выбора конфигурации по CV.

Grid Search проверил 27 комбинаций, Random Search — 27 уникальных случайных комбинаций в тех же границах. У каждого — 135 CV обучений. Настраивались `n_estimators`, `learning_rate`, `max_depth`.

| Модель | Mean CV F1 | Std CV F1 | Test F1 |
|---|---:|---:|---:|
| Исходная | 0,7642 | 0,0219 | **0,7360** |
| Лучшая Grid | **0,7672** | 0,0103 | 0,7244 |
| Лучшая Random | 0,7671 | 0,0254 | 0,7258 |

По заранее заданному правилу финальной выбрана конфигурация Grid. Небольшой прирост CV качества не подтвердился на локальном test, поэтому модель после его просмотра не менялась. Этот test уже использовался в ЛР2; независимая внешняя выборка в материалах курса отсутствует.
