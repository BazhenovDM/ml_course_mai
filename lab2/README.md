## Суть задания

По признакам пассажира предсказать `Survived` (1 — выжил, 0 — нет). Требуются первичный анализ, корректная подготовка данных и стратифицированное разбиение, `DummyClassifier` с наиболее частым классом, Decision Tree, Random Forest, Gradient Boosting, SVM и KNN. Для всех моделей нужны Accuracy, Precision, Recall, F1 для класса 1 и матрица ошибок. Основная метрика и критерий leaderboard — **F1 для `Survived = 1`**, порог задания — **строго F1 > 0,70**. Также нужны сравнение моделей, важность признаков для трёх древесных моделей и анализ ошибок лучшей модели. Детали и порядок работы — в [PLAN.md](PLAN.md).

Тестовая часть использована для итоговой оценки. Преобразования и подбор параметров выполнены только на обучающих данных. По 5-кратной CV выбран Gradient Boosting (CV F1 = 0,764); его локальный test F1 = 0,736. SVM получил на этом test F1 = 0,760, но выбор модели после просмотра теста не менялся. Все показатели и ошибки разобраны в notebook.

Дерево с критерием Джини и обращением из имени получило F1 0,756 на исходных пяти сгибах и 0,774 на локальном test. Этот test уже неоднократно просматривался, поэтому результат требует подтверждения на внешней выборке.

Для KNN выбран вариант с категориальным классом билета и заполнением возраста по полу и классу. На исходных пяти сгибах F1 составляет 0,759, на уже просмотренном локальном test — 0,704. На двух дополнительных разбиениях train преимущество относительно прежнего KNN не сохранилось. Итоги опытов сохранены в плане.
